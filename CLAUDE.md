## Agent skills

### Issue tracker

Issues live in GitHub Issues (`lienardquentin/claude-code-shenanigans`), via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Standards

What a change must not hold, blocking and minor: `docs/agents/standards.md`. Theseus's reviewers judge every change by it.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
